# Yeet

Styles Yeet's launcher window, search entry and application list with the active Noctalia palette.

Install Yeet, then enable **Yeet** in **Noctalia Settings -> Templates**.

## Output

- `$XDG_CONFIG_HOME/yeet/style.css`

This replaces the stylesheet at that path; back up any custom CSS before enabling it. No hooks, configuration edits or reload commands are included.
