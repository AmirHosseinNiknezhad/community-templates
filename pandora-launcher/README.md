# Pandora Launcher

Generates a **Noctalia** theme for Pandora Launcher.

Install Pandora Launcher and enable **Pandora Launcher** in **Noctalia Settings -> Templates**. The theme is written to `$XDG_DATA_HOME/PandoraLauncher/themes/noctalia.json`. Select **Noctalia** in the launcher's theme settings manually.

Back up any existing file at that path: generation replaces it. No hook changes launcher settings or triggers a reload.
